## 二维码回归

[`tests/qr-v4.test.cjs`](../tests/qr-v4.test.cjs) 单独执行 **1 项通过、0 跳过**。测试直接运行实际 `app/qr.js` 和打包的 `qrcode.mjs`，使用真实 Canvas 生成 PNG，没有替换编码器或伪造像素结果。

覆盖 URL、中文内容、多段长文本，以及默认与自定义深浅配色。对每张 700 × 700 PNG：

1. 扫描全图像素，确认只有指定的前景与背景色。
2. 检查四边完整的四模块留白。700 像素并非总能整除模块数量，容许整数栅格边界不足 1 像素的取整差异。
3. 比对每个码区模块中心，确认留白调整没有裁切或改变符号内容。
4. 使用环境中已有的独立 jsQR 解码器解码实际 PNG，三种内容均与输入原文一致。

独立解码器和原生 Canvas 属于当前验证环境；没有为此新增发行依赖。缺少独立解码器的环境仍执行像素与模块检查，并在测试诊断中说明范围。留白依据为 [DENSO WAVE 官方二维码区域说明](https://www.qrcode.com/en/howto/code.html)。这不替代用户对最终排版、缩放与印刷结果的实机扫码检查。
